# 🌐 LRG Store Shop
**LRG Store Shop** es una plataforma de comercio electrónico (e-commerce) moderna, elegante y funcional, diseñada para ofrecer una experiencia de compra en línea fluida, ágil y segura. El proyecto combina un diseño visual atractivo con una interfaz intuitiva (UI/UX) enfocada en facilitar la navegación del usuario, la exploración de catálogos y la conversión eficiente de ventas.

🌐 **Sitio Web Oficial:** [lrg-store-shop.vercel.app](https://lrg-store-shop.vercel.app/)

# 💡 ¿No eres programador? Te lo explicamos en simple
Si no tienes experiencia en tecnología o desarrollo web, aquí te explicamos fácilmente de qué trata esta plataforma:

**¿De qué se trata la página?:** Es una tienda virtual completa e interactiva. Funciona como un escaparate digital donde los clientes pueden explorar diferentes artículos, filtrarlos por categoría, ver detalles específicos y gestionar sus compras a través de un carrito.

**¿Para qué sirve?:** Permite a una marca o negocio vender sus productos por internet las 24 horas del día de manera organizada, profesional e higiénica para el usuario.

**¿Por qué es rápida e interactiva?:** Utiliza tecnología web de última generación que permite agregar o quitar productos del carrito, cambiar de categorías o buscar artículos al instante sin molestas recargas de pantalla.

**¿Cómo se ve en celulares?:** Cuenta con un diseño adaptativo (responsive), garantizando que la tienda, las imágenes y el proceso de compra se vean y funcionen a la perfección desde cualquier smartphone, tablet o computadora.

# 🚀 ¿Qué es LRG Store Shop?
Esta tienda actúa como la solución central e-commerce para la marca. Está optimizada técnicamente para garantizar una experiencia de compra sin fricciones mediante las siguientes características:

**Catálogo Interactivo y Filtrado:** Presentación limpia de productos con navegación por categorías y búsqueda ágil.
**Carrito de Compras en Tiempo Real:** Gestión de productos seleccionados, cantidades y cálculo del total al instante.
**Arquitectura Enfocada en Conversión:** Flujos de compra optimizados para guiar al usuario directo al proceso de pago o contacto.
**Rendimiento UI Excepcional:** Tiempos de carga mínimos y animaciones fluidas para asegurar retención de usuarios.
**Diseño Responsive & Mobile-First:** Adaptabilidad total a cualquier dispositivo, optimizando la experiencia en teléfonos móviles.

# 🛠️ Stack Tecnológico
El proyecto está desarrollado con un enfoque modular y moderno para garantizar estabilidad, escalabilidad y facilidad de mantenimiento.

### Frontend & UI
**Tecnologías Web Modernas:** Estructura modular orientada a un renderizado rápido y eficiente.
**CSS / Frameworks Visuales:** Estilos adaptativos, diseño flexible y componentes UI limpios para una interfaz atractiva.
**Lógica de Cliente:** Scripts interactivos para la gestión dinámica del carrito y catálogo.

### Calidad de Código & Estándares
**Clean Code:** Estructura de archivos limpia, ordenada y modular para escalabilidad del e-commerce.
**Compatibilidad Multi-Navegador:** Funcionamiento consistente en Google Chrome, Safari, Firefox, Edge y navegadores móviles.

### Infraestructura & Cloud
**Vercel Edge Network:** Despliegue global en la nube con distribución perimetral para máxima velocidad de respuesta.

# ⚙️ Requisitos Previos
Para ejecutar o modificar este proyecto localmente se recomienda contar con un entorno de desarrollo de Node.js o el gestor de paquetes de tu preferencia (NPM, Yarn o Bun).

🚀 Instalación y Uso Local
Clonar el repositorio:

´´´Bash
git clone https://github.com/leoogomez7/lrg-store-shop.git
cd lrg-store-shop
Instalar dependencias:

Bash
npm install
# o bien
bun install
Ejecutar el servidor local de desarrollo:

Bash
npm run dev
# o bien
bun run dev
Compilar para producción:

Bash
npm run build
# o bien
bun run build
